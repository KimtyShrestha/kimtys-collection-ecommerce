# Kimty's Collection — E-Commerce Platform

A user-centred e-commerce web application for Kimty's Collection, a children's
retail store operating in Kathmandu Valley, Nepal. Developed as part of the
ST6012CEM User Experience Design coursework (Coventry University / Softwarica
College of IT & E-Commerce).

## Project Context

Kimty's Collection has operated for ~18 years across three physical branches
(Banasthali, Basundhara, Hattigauda), selling primarily in-store and via
Facebook Messenger. This project applies a complete User-Centred Design
process — research, personas, low-fidelity prototyping, usability testing, and
iterative improvement — to deliver an online shopping experience for its
customers.

## Technology Stack

- **Frontend:** React, Vite, React Router, Axios, Tailwind CSS, React Hook Form, Lucide Icons
- **Backend:** Node.js, Express
- **Database:** PostgreSQL
- **Authentication:** JWT, bcrypt, role-based access (Customer / Admin)
